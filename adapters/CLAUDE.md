@AGENTS.md

Project rules live in `AGENTS.md` at the repository root, imported above. On
conflict, `AGENTS.md` prevails. Run its `init` and `context` commands (see
`AGENTS.md`) before coding, and `claim`/`pause`/`handoff`/`review`/`done` to
take, pass on and close tasks (in Factory mode `next` names the task and `recall` its
context). Always use the same agent id (the one in its
`## Agent identity` table when there is one), never a new one per session.
